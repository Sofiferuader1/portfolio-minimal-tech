## Tecnologías
HTML5, CSS3, JavaScript vanilla e Inter (Google Fonts). Sin frameworks JavaScript ni constructores visuales.

## Estructura
- `index.html`: portfolio one-page con nueve secciones.
- `coffea.html`: caso de estudio académico de Coffea.
- `styles.css`: diseño Minimal Tech responsive.
- `script.js`: apertura y cierre del menú mobile accesible.
- `assets/`: favicon y gráfica social SVG.

## Proyectos
Coffea y Cubri Seguros se presentan como proyectos académicos. TaskFlow es una propuesta **conceptual** y no una aplicación desarrollada. Los mockups de las tarjetas son conceptuales; pueden reemplazarse por capturas reales. El caso de estudio Coffea incorpora una ilustración conceptual creada con IA, identificada como tal y no como evidencia del proyecto original.

## Proceso UX/UI
La investigación, proto-persona, benchmark, moodboard, sitemap, wireframes y design system se documentan en Figma. Las pruebas de usabilidad con tres personas están pendientes de realización y registro.

## Diseño y fuentes
Paleta Minimal Tech: marfil `#F6F2EA`, grafito `#2C2C2C`, salvia `#A3B18A`. Fuente Inter de Google Fonts. Diseño basado en el trabajo de Figma creado para este proyecto. No se utilizó un template externo.

## Uso de IA
Se utilizó asistencia de IA para proponer contenido, documentación y generar una base de HTML, CSS y JavaScript. El diseño y los textos deben revisarse, corregirse y validarse por la autora antes de la entrega.

## Publicación en GitHub Pages
1. Subir los archivos al repositorio público en la raíz de la rama `main`.
2. Abrir `Settings > Pages`.
3. Elegir `Deploy from a branch`, `main` y carpeta `/(root)`.
4. Guardar y esperar el despliegue automático. Cada push a `main` publicará los cambios.
5. Pegar aquí la URL HTTPS definitiva.

## Pruebas de usabilidad

Se realizó una prueba de usabilidad con tres participantes utilizando el portfolio publicado en GitHub Pages.

**Tareas evaluadas:**
1. Encontrar las tecnologías y herramientas utilizadas.
2. Explorar el caso de estudio Coffea y regresar al portfolio.
3. Localizar el correo electrónico de contacto.

**Resultados:**
- Participantes: 3.
- Tareas completadas: 9 de 9 (100 %).
- Los tres participantes lograron completar las tareas propuestas.

**Problema detectado:**

Una participante informó que la imagen del caso Coffea aparecía en blanco y no se visualizaba correctamente.

**Corrección realizada:**

Se identificó que faltaban archivos de la carpeta `assets` en el repositorio. Se incorporaron los archivos correspondientes y se verificó que la imagen se visualizara correctamente en el sitio publicado.

**Conclusión:**

Las tareas pudieron completarse y la evaluación permitió detectar y corregir un problema real de visualización.
